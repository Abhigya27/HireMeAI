MediaShare is an Instagram-style media-sharing app I built mainly as a backend showcase, focused on the parts real production systems need beyond basic CRUD. It has OAuth2 and JWT authentication with bcrypt password hashing, per-user rate limiting on uploads, and ownership-enforced permissions so only the original poster can delete a post. 

MediaShare's data layer uses async SQLAlchemy 2.0 on a persistent PostgreSQL database via Supabase, including a self-healing schema migration that safely adds new columns without wiping existing data. Media is served through ImageKit's CDN, and the API is fully documented with OpenAPI and Swagger. Built with FastAPI and Streamlit.

HireMeAI is an AI-powered portfolio assistant I built that lets recruiters chat with my profile and evaluate my resume against a job description. It combines a history-aware RAG pipeline (FastEmbed and FAISS) for conversational Q&A with an agentic GitHub research agent. When asked implementation-level questions, the backend autonomously reads my repository's actual source code through LLM tool-calling and answers grounded in real code, not static text. 

HireMeAI also runs a separate JD-matching engine that scores resume fit from 0 to 100 against a job posting using embeddings and LLM reasoning. Built with FastAPI, Streamlit, and SQLite; deployed on Railway and Streamlit Cloud. it does not use LangChain.

ScrubGPT turns an entire YouTube playlist into a searchable, timestamp-aware knowledge base. It extracts transcripts, preserves timestamps by chunking before translation, and stores dense and BM25 sparse vectors in Qdrant for hybrid retrieval, combining semantic and keyword search rather than similarity alone. Answers pass a grounding check and cite the exact timestamp they came from, avoiding hallucinated answers. 

ScrubGPT's ingestion pipeline is resumable and cache-aware, distinguishing expected, temporary, and unexpected failures so long jobs stay reliable. I also built a retrieval evaluation harness to test answer quality across direct, paraphrased, and multi-video queries. Built with FastAPI, Streamlit, and Qdrant.
